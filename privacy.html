LIZZREAD 隐私政策

最后更新：2026-11-22 · 适用于网页版、iOS 与 Android 客户端

一句话总结

LIZZREAD 不要求注册，不收集你的个人身份信息，不投放广告，不做用户画像。你的阅读进度、生词本、笔记都只保存在你自己的设备上。

1. 我们保存在本机的内容

  • 阅读进度、书架、标记、金句、生词本、复习记录、词汇测试等级、学习统计
  • 已下载的书籍全文、译文缓存、句子包
  • 偏好设置（主题、字号、展示语言、学习语言等）

以上数据存放在浏览器的 localStorage 与 IndexedDB（App 内为系统 WebView 的本地存储），不会上传到我们的服务器。清除浏览器数据或卸载 App 会一并删除。

2. 联网时会发送什么

  • 翻译：你点“翻译本章/这句”或点词时，对应的文本片段会发送给第三方机器翻译服务（Google 翻译 / MyMemory / 自建 Bing 代理）以获得译文。
  • 公版书正文：首次阅读某本书时，App 会从 Project Gutenberg 镜像或青空文库下载该书的公版全文。
  • 匿名计数：仅上报“某语言发生了某操作”的次数（如 ja_lookup），不包含任何内容、设备标识或个人信息。

我们不会绑定你的身份，也不会跨应用或跨网站追踪你。

3. 我们不做的事

  • 不收集姓名、手机号、邮箱、位置、通讯录、相册
  • 不做广告投放，不向第三方出售或共享数据
  • 不使用 IDFA / 广告标识符，不进行跨 App 追踪

4. 订阅与支付

网页版的订阅由第三方支付通道处理，我们只接收“是否已支付”的结果，不接触你的银行卡信息。iOS 版若通过 App 内购买订阅，支付由 Apple 处理，我们同样无法获取你的支付凭据。

5. 儿童

本产品适合全年龄使用，不会有意收集儿童的个人信息。

6. 内容来源与版权

书库中的作品均为公有领域（作者去世超过 70 年）或明确标注为译本的公版内容，来源为 Project Gutenberg、青空文库等公开项目。若权利人认为存在误收，请通过下方邮箱联系我们，我们会在 48 小时内下架。

7. 你的权利

你可以随时在“个性化 → 清空缓存”中删除本机全部数据；也可以卸载 App。由于我们不保存你的数据，无需额外申请删除。

8. 变更

本政策更新会在此页面发布并更新顶部日期；重大变更会在 App 内提示。

9. 联系方式

邮箱：support@lizzread.local（上架前请替换为真实邮箱）
