## 二、后台填写顺序（AGC 控制台）

1. **我的应用 → 新建应用**
   - 应用名称：LIZZREAD
   - 包名：`com.lizzread.app`
   - 分类：教育 → 阅读
   - 默认语言：简体中文

2. **应用信息 → 基本信息**
   - 图标：`icon-216.png`
   - 应用介绍：复制 `上架文案.md` 里的「应用介绍」
   - 应用一句话简介：`16 门语言的经典原著阅读器：点词即查释义、整章翻译、句子拼装、生词复习。`
   - 客服邮箱、隐私政策网址（填写你部署后的 `https://.../privacy.html`）

3. **版本信息 → 上传 APK**
   - 上传 `LIZZREAD-2.0.0-release.apk`
   - 版本号自动识别为 2.0.0（versionCode 20000）
   - 更新说明：复制 `上架文案.md` 的「更新说明」

4. **内容分级**
   - 全部选「否」，年龄分级 3+

5. **隐私与安全**
   - 数据安全表单：不收集个人身份信息
   - 权限说明：只使用 INTERNET（如系统提示，写「下载公版书籍与翻译服务」）

6. **软件著作权**
   - 上传证书扫描件（中国版权保护中心发放）
   - 若尚未取得：华为允许「承诺函」先审，但必须在规定期限内补交（建议直接等证书）

7. **提交审核**
   - 审核时长 1–3 个工作日
   - 常见退回原因见 `store/huawei/README-HUAWEI.md`

## 三、上架前自查（逐项打勾）

- [ ] APK 是 **release 签名**（不是 debug）
- [ ] 包名 `com.lizzread.app` 与 AGC 后台一致
- [ ] versionCode 比上一版大（首次 20000 即可）
- [ ] 图标 216×216 无透明通道
- [ ] 截图 ≥3 张，尺寸 ≥1080×1920
- [ ] 隐私政策网址可打开（不是 localhost）
- [ ] 文案里写明「公有领域作品」
- [ ] 应用内不出现外部支付链接（App 版已自动隐藏激活码入口）
- [ ] 华为 IAP 的 4 个商品已创建（若本次要卖会员）
