## 应用介绍（详细，≤3000 字）

```
LIZZREAD 是一个为外语学习者打造的经典原著阅读器。全部书籍均为公有领域作品
（作者逝世超过 70 年），来自 Project Gutenberg、青空文库等公开项目，无需付费即可阅读。

【16 门语言，一个界面】
英语、中文、德语、法语、意大利语、西班牙语、日语、韩语、荷兰语、葡萄牙语、
拉丁语、希腊语、芬兰语、匈牙利语、瑞典语、世界语。每门语言有独立书库与等级标准
（CEFR / HSK / JLPT / TOPIK / 拉丁 T1-T4）。

【点一个词，四种帮助】
- 常用义：内置 24 万词词典，离线也能查
- 本句语境义：结合上下文给出这一句里的意思
- 英英释义 + 音标 + 发音：想看原语解释时展开
- 多语言对照：同一词在 16 种语言里怎么说，可折叠

【整章翻译】
一键把整章译文填到每句下方，译文会缓存，断网也能看。

【句子拼装】
把打乱的意群按正确语序拼回去，练的是语感。答案默认隐藏，看过答案不计分。

【生词本与间隔重复】
点词时一键加入生词；颜色标记区分「陌生 / 学习中 / 已掌握」；
生词模式用间隔重复算法帮你反复记忆。

【导入自己的书】
支持 EPUB / PDF / TXT / DOCX / Markdown 等 16 种格式；
也支持「网址导入」：Gutenberg、青空文库、维基文库、RSS 订阅、任意网页正文。

【学习报告】
阅读时长、查词数、拼装正确率、连续打卡天数，可导出报告。

【关于内容与版权】
本应用全部书籍为公有领域作品，来源已在书内标注。若权利人认为存在误收，
可通过客服邮箱联系我们，我们会在 48 小时内下架。

【关于会员】
阅读、查词、生词本永久免费。翻译额度、离线整书下载、学习报告导出为会员功能，
可在应用内通过华为应用内购买订阅。
```
