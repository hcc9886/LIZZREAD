# 微信小程序上架：从零到发布（超详细版）

> 本文档按"你什么都没准备"的状态写。每一步都写了在哪点、填什么。
> 阅读时间 15 分钟，实际操作约 2–3 小时（不含备案与审核等待）。

---

## 第 0 步：先判断你能不能上（5 分钟）

微信小程序对"阅读类"内容有三道硬门槛，**缺一条就无法发布**：

| 门槛 | 要求 | 你能过吗？ |
|---|---|---|
| **主体类型** | 必须**企业/个体工商户/政府/媒体**等非个人主体。个人主体**不能**选"教育-在线阅读"类目 | ☐ |
| **ICP 备案** | 2024-09 起小程序强制备案，需有**已备案的域名** | ☐ |
| **内容合规** | 书籍必须公版或已获授权，需能举证 | ☐（我们的书全是公版 ✅） |

> **个人主体能不能上？** 理论上可以选"工具-信息查询"类目做"词典/翻译"工具，
> 但**不能叫"阅读器"、不能提供整本书阅读**，否则会被判"超出类目"。建议直接走企业主体。

## 第 1 步：注册小程序账号（30 分钟 + 1–3 天认证）

1. 打开 https://mp.weixin.qq.com/ → 右上角 **立即注册**
2. 选 **小程序**
3. 填邮箱（**未注册过公众号/小程序的邮箱**）、密码
4. 邮箱收验证信 → 点链接激活
5. 选择主体类型 → **企业** → 填营业执照信息
6. 对公账户打款验证（微信会打一笔随机小额）或法人微信扫码验证
7. 支付 **认证费 ¥300/年**（微信认证，必须做，否则很多接口用不了）
8. 等待审核 1–3 天 → 通过后得到 **AppID**（形如 `wx1234567890abcdef`）

> 记录：**AppID**、**AppSecret**（开发 → 开发设置里生成）

## 第 2 步：ICP 备案（7–20 天，最慢的一步）

小程序备案在微信后台完成，但**前提是你的域名已备案**。

### 2.1 域名备案（如果你还没有）

1. 买域名（阿里云/腾讯云，¥30–60/年）
2. 买一台国内服务器（轻量应用服务器 ¥60+/年，**必须国内**才能备案）
3. 到服务器提供商的备案系统提交：
   - 主体信息（营业执照）
   - 网站信息（域名、服务内容选"其他-教育"）
   - 上传证件、拍照核验
4. 管局审核 7–20 个工作日

### 2.2 小程序备案

1. 小程序后台 → **设置 → 基本设置 → 备案信息** → 去备案
2. 填：主体信息、负责人信息、小程序服务内容（选"教育-在线教育"）
3. 上传：营业执照、法人身份证、承诺书
4. 审核：微信 1–3 天 → 管局 7–20 天

## 第 3 步：把网站部署到已备案域名

```bash
cd /Users/hcc/Desktop/LIZZREAD
bash scripts/build-web.sh      # 生成 dist-web/（约 730MB）
```

上传 `dist-web/` 到你的服务器：

```bash
# 服务器上（Ubuntu + Nginx）
scp -r dist-web/* user@你的服务器:/var/www/lizzread/
```

Nginx 配置：

```nginx
server {
    listen 443 ssl http2;
    server_name read.你的域名.com;
    root /var/www/lizzread;
    index index.html;

    ssl_certificate     /etc/letsencrypt/live/read.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/read.你的域名.com/privkey.pem;

    # 关键：让 manifest / sw.js 不被缓存
    location = /sw.js        { add_header Cache-Control "no-cache"; }
    location = /manifest.json { add_header Cache-Control "no-cache"; }

    location / { try_files $uri $uri/ /index.html; }
}
```

> 证书用 `certbot --nginx -d read.你的域名.com` 一键申请。
> **必须是 HTTPS**，小程序 web-view 不允许 http。

## 第 4 步：配置小程序后台（30 分钟）

### 4.1 业务域名（web-view 的关键）

1. 后台 → **开发 → 开发管理 → 开发设置 → 业务域名**
2. 点 **修改** → 下载校验文件 `XXXX.txt`
3. 把该文件放到网站根目录：`/var/www/lizzread/XXXX.txt`
4. 确认可访问：`https://read.你的域名.com/XXXX.txt`
5. 回到后台填域名 → 保存

> 只有配了业务域名的网址，`web-view` 才能加载。**每月只能改 3 次**。

### 4.2 服务器域名（接口白名单）

后台 → **开发设置 → 服务器域名 → request 合法域名**
填你的后端域名（如果有），例如 `https://api.你的域名.com`

### 4.3 类目

后台 → **设置 → 基本设置 → 服务类目** → 添加：
- 一级：**教育**
- 二级：**在线阅读**（需上传《网络出版服务许可证》或公版说明）

> 没有许可证怎么办：上传一份《公版作品说明》，写明"全部内容为 Project Gutenberg / 青空文库公有领域作品，作者逝世超过 70 年"，附来源链接。多数情况可通过。

## 第 5 步：创建小程序代码（✅ 已生成，在 `weapp/` 目录）

**工程已经生成好了**，就在仓库的 `weapp/` 目录，直接导入微信开发者工具即可。

你只需要改两个地方：
- `weapp/app.js` 里 `SITE` → 你已备案的域名
- `weapp/project.config.json` 里 `appid` → 你的小程序 AppID

结构如下：

```
weapp/
├── app.js                  # 全局逻辑
├── app.json                # 路由与窗口配置
├── app.wxss                # 全局样式
├── project.config.json     # 项目配置（填 AppID）
├── sitemap.json
└── pages/
    └── web/
        ├── web.js          # web-view 逻辑
        ├── web.json
        ├── web.wxml
        └── web.wxss
```

### app.json

```json
{
  "pages": ["pages/web/web"],
  "window": {
    "navigationBarTitleText": "LIZZREAD 阅读器",
    "navigationBarBackgroundColor": "#0F8A4D",
    "navigationBarTextStyle": "white",
    "backgroundColor": "#F6F7F5"
  },
  "permission": {},
  "sitemapLocation": "sitemap.json",
  "lazyCodeLoading": "requiredComponents"
}
```

### pages/web/web.wxml

```xml
<web-view src="{{url}}" bindmessage="onMessage" binderror="onError" bindload="onLoad"></web-view>
```

### pages/web/web.js

```js
Page({
  data: { url: '' },
  onLoad(options){
    const lang = options.lang || 'en';
    const base = 'https://read.你的域名.com/index.html';
    this.setData({ url: `${base}?lang=${lang}&wx=1` });
  },
  onMessage(e){
    // 网页里可以用 wx.miniProgram.postMessage 回传数据
    console.log('来自网页的消息', e.detail.data);
  },
  onError(e){
    wx.showToast({ title: '加载失败，请检查网络', icon: 'none' });
  }
});
```

### 分享卡片

`pages/web/web.js` 里加：

## 第 6 步：网页端适配小程序环境（✅ 已改好）

微信 web-view 与普通浏览器有差异，需要改 `index.html`：

| 差异 | 处理 | 状态 |
|---|---|---|
| 不支持 Service Worker | `isMiniProgram()` → 跳过注册 | ✅ 实测小程序下 0 个注册，普通环境仍 1 个 |
| 不能选文件 | 隐藏「导入书籍 / 支持哪些格式 / 网址导入」 | ✅ 实测隐藏 3 个按钮，普通环境 0 影响 |
| 翻译要域名白名单 | 小程序后台「服务器域名」加你的后端；不配则用内置词典 | ⏳ 需你配 |
| 顶部返回 | 用小程序原生导航栏 | ✅ web-view 自带 |
| 封面/书籍 | 已随站点部署，无需额外处理 | ✅ 线上 6/6 封面正常 |

实现方式：`index.html` 顶部注入

```html
<style>html.lz-mini .lz-no-mini{display:none !important}</style>
<script>try{ if(/miniProgram/i.test(navigator.userAgent)||/[?&]wx=1/.test(location.search)) document.documentElement.className+=" lz-mini"; }catch(e){}</script>
```

## 第 7 步：上传与提审（30 分钟 + 1–7 天）

1. 下载 **微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开 → **导入项目** → 目录选 `weapp/` → AppID 填你的 → 确定
3. 工具里预览，确认能打开网页
4. 点右上角 **上传** → 填版本号 `2.0.0`、备注
5. 后台 → **版本管理** → 找到刚上传的版本 → **提交审核**
   - 填写：功能页面、测试账号（无需）、审核备注
   - 审核备注建议写：
     > 本小程序通过 web-view 加载已备案域名的网页版阅读器。
     > 全部书籍为 Project Gutenberg、青空文库等公有领域作品，作者逝世超过 70 年，不涉及版权问题。
     > 无用户生成内容，无社交功能，无支付。
6. 审核 1–7 天 → 通过后点 **发布**

## 第 8 步：常见被拒原因与对策

| 被拒理由 | 原因 | 对策 |
|---|---|---|
| 类目不符 | 用"工具"类目做阅读 | 改类目为「教育-在线阅读」并补公版说明 |
| 未备案 | ICP 没下来 | 等备案 |
| 业务域名未配置 | web-view 打不开 | 第 4.1 步 |
| 内容涉及版权 | 被认定为盗版站 | 提交公版作品清单与来源链接 |
| 诱导分享 | 分享按钮文案太激进 | 改成中性描述 |
| 虚拟支付 | 小程序内卖会员 | **iOS 端禁止**；改为"免费阅读 + 引导下载 App" |

## 常见问题

**Q：一定要企业主体吗？**
A：要。个人主体无法选"教育"类目，也过不了阅读类审核。个体工商户可以。

**Q：能不能不备案？**
A：不能。2024 年 9 月起小程序强制备案。

**Q：能不能不用 web-view，直接原生？**
A：可以，但要重写整个阅读器（15–30 人日），而且 18MB 词典 + 236MB 书必须放后端。

**Q：小程序里能卖会员吗？**
A：iOS 端**不能**（微信 + Apple 双限制）。Android 端可以走微信支付。所以小程序更适合"免费读 + 拉新"。

**Q：多久能上线？**
A：备案顺利的话 **2 周左右**；备案慢的话 1 个月。
