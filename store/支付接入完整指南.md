# 问题一：iOS 端在微信小程序不能用微信支付吗？

## 答案：**是的，不能用。**

| 场景 | 微信支付 | 谁限制的 |
|---|---|---|
| 安卓手机 · 微信小程序 | ✅ 可以 | — |
| **iPhone · 微信小程序** | ❌ **不可以** | **微信 + Apple 双重限制** |
| iPhone · Safari 打开网页版 | ✅ **可以** | — |
| iPhone · 添加到主屏幕的 PWA | ✅ **可以** | — |
| iPhone · App Store 的 App | ❌ 不可以 | Apple 强制 IAP |

## 为什么

1. **微信的规则**《微信小程序平台运营规范》：
   小程序内购买虚拟商品（课程、会员、数字内容）必须使用微信支付。
   **但 iOS 端**因为 Apple 的 App Store 规则，微信官方**直接禁止** iOS 小程序的虚拟支付功能。

2. **Apple 的规则** 3.1.1：
   App 内出售数字内容必须走 IAP，且不能引导用户去外部支付。
   微信小程序运行在 iOS 上，同样受限。

**结论**：这不是技术问题，是平台规则，谁做都绕不过去。

## 那 iPhone 用户怎么付钱？

| 方式 | 可行性 | 怎么做 |
|---|---|---|
| **Safari 打开网页版** | ✅ 最佳 | 微信 H5 支付直接拉起微信 |
| **添加到主屏幕（PWA）** | ✅ 一样 | 本质是网页，不受限 |
| 激活码 | ✅ 100% 可用 | 直接输入即开通 |
| 换安卓手机 | ✅ | 安卓小程序可微信支付 |

**代码已实现**：iOS 小程序点「开通」会自动弹出说明，引导用户：
① 用激活码在此开通 ② 复制链接去 Safari ③ 换安卓

## 实测结果（四种环境自动分流）

| 环境 | 系统返回 | 行为 |
|---|---|---|
| 网页 / APK | `{"mode":"web","pay":true}` | 显示支付宝 + 微信 + 激活码 |
| 安卓小程序 | `{"mode":"mini_android","pay":true}` | 微信支付 |
| iOS 小程序 | `{"mode":"mini_ios","pay":false}` | 弹窗引导激活码/网页版 |
| 商店包 | `{"mode":"store"}` | IAP |

# 问题二：我该怎么让网站可以支付？

## 2.1 整体流程（三步）

```
第一步：办营业执照（个体工商户即可）        1–3 天
第二步：申请支付宝商户号 + 微信支付商户号      1–5 天
第三步：把密钥填到服务器环境变量，重启        5 分钟
```

代码**我已经全部写好**，你只要填密钥。

## 2.2 第一步：办个体工商户

| 步骤 | 操作 |
|---|---|
| 1 | 支付宝搜索「个体工商户注册」，或下载当地政务 App（浙里办/粤省事/随申办） |
| 2 | 填身份证 + 手机号 |
| 3 | 经营范围写「文化创意服务；图书零售；软件开发」 |
| 4 | 起名如「XX文化创意工作室」 |
| 5 | 1–3 天下证，下载电子营业执照 |

**费用**：执照 ¥0，刻章 ¥0–200

## 2.3 第二步 A：申请支付宝

| 步骤 | 操作 | 链接 |
|---|---|---|
| 1 | 用企业支付宝登录开放平台 | https://open.alipay.com/ |
| 2 | 控制台 → 网页/移动应用 → 创建应用 | — |
| 3 | 应用类型选 **「手机网站支付」**（手机端）和 **「电脑网站支付」**（电脑端） | — |
| 4 | 上传营业执照，提交审核 | 1–3 天 |
| 5 | 审核通过后，在「开发设置」里生成 **RSA2 密钥** | — |

**拿到三样东西**：
- **AppID**（应用 ID）
- **应用私钥**（你生成，自己保存，**不要给别人**）
- **支付宝公钥**（支付宝提供）

**费率**：0.6%，T+1 到企业账户

## 2.4 第二步 B：申请微信支付

| 步骤 | 操作 | 链接 |
|---|---|---|
| 1 | 注册商户号 | https://pay.weixin.qq.com/ |
| 2 | 提交营业执照、法人身份证、结算账户 | — |
| 3 | 审核 | 1–5 天 |
| 4 | 登录商户平台 → 账户中心 → API 安全 | — |
| 5 | 设置 **API v3 密钥**（自己设一个 32 位字符串） | — |
| 6 | 申请 **API 证书**，下载 `apiclient_key.pem` | — |
| 7 | 关联 AppID（小程序/公众号的 AppID） | — |

**拿到五样东西**：
- **商户号 mchid**
- **AppID**（关联的小程序或公众号 AppID）
- **API v3 密钥**
- **证书序列号**（API 证书里能看到）
- **apiclient_key.pem**（私钥文件内容）

**费率**：0.6%，T+1 到商户号

## 2.5 第三步：填到服务器

代码已经写好（`server/pay.js`），你只需要设置环境变量。

### 支付宝

```bash
export ALIPAY_APP_ID=2021000000000000
export ALIPAY_PRIVATE_KEY="$(cat 应用私钥.pem)"
export ALIPAY_PUBLIC_KEY="$(cat 支付宝公钥.pem)"
```

### 微信支付

```bash
export WXPAY_MCHID=1600000000
export WXPAY_APPID=wx1234567890abcdef
export WXPAY_API_V3_KEY=你的32位密钥
export WXPAY_SERIAL=证书序列号
export WXPAY_PRIVATE_KEY="$(cat apiclient_key.pem)"
```

### 站点地址

```bash
export PAY_BASE_URL=https://你的域名.com
```

### 启动

```bash
node server.js 8765
```

## 2.6 已实现的功能（我写好的）

| 接口 | 作用 |
|---|---|
| `GET /api/pay/config` | 告诉前端哪些支付渠道可用 |
| `POST /api/pay/create` | 下单：支付宝返回跳转链接，微信返回二维码 |

| `POST /api/pay/notify/wechat` | 微信回调（**AES-256-GCM 解密**） |

## 2.7 前端行为

| 情况 | 用户看到的 |
|---|---|
| 已配置支付宝 | 弹窗显示「支付宝支付」按钮 → 跳转收银台 |
| 已配置微信 | 弹窗显示「微信扫码支付」→ 显示二维码 → 支付后自动开通 |
| 都没配置 | 「在线支付尚未开通，当前可用激活码开通」 |
| 支付成功 | 自动开通会员 + 提示「✅ 支付成功」 |

用户付款后：
1. 平台回调服务器
2. 服务器验签 → 标记订单已支付
3. 前端每 3 秒查一次状态
4. 查到已支付 → 自动写入会员 + 提示

## 2.8 测试环境（不用真钱）

支付宝有**沙箱环境**，可以先用假钱测：

1. 打开 https://open.alipay.com/develop/sandbox/app
2. 拿到沙箱 AppID、私钥、公钥
3. 把 `pay.js` 里的网关改成 `https://openapi.alipaydev.com/gateway.do`
4. 用沙箱买家账号付款

微信支付没有沙箱，只能小额真测（比如 1 分钱）。

## 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 支付宝回调收不到 | 服务器不通外网 / 不是 HTTPS | 配 HTTPS + 开 443 |
| 微信回调解密失败 | API v3 密钥填错 | 重新设置 |
| 支付成功但没开通 | 回调没到或被防火墙拦 | 看服务器日志 |
| iOS 小程序点支付没反应 | 微信禁止 | 正常，会弹窗引导 |
