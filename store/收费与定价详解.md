# B. 站内会员怎么收（用户付给你的）

## B1. 定价表（已上线）

| 套餐 | 价格 | 折合 | 适合谁 |
|---|---|---|---|
| 免费版 | ¥0 | — | 英语 120 句/天、其他语言各 80 句/天；16 门语言全部可浏览 |
| 单语言会员 | **¥28/月** | ¥28/月 | 只学一门语言（英语已免费，无需购买） |
| 全语言 · 月 | **¥58/月** | ¥58/月 | 短期冲刺 |
| 全语言 · 季 | **¥128/季** | ¥42.7/月 | 一个学期 |
| 全语言 · 年 | **¥388/年** | ¥32.3/月 | 长期学习（**性价比最高**） |

> 定价逻辑：单语言 ¥28 与全语言月付 ¥58 的差价只有 2 倍，但覆盖 16 门语言，
> 多数用户会直接选全语言；年付折合 ¥32/月，比单语言还便宜，进一步推动年付。

## B2. 各渠道的售价必须一致（但要扣除抽成）

| 渠道 | 用户看到的价格 | 你实际到手（扣除抽成） |
|---|---|---|
| 网页版 / 激活码 | ¥28 / ¥58 / ¥128 / ¥388 | **100%**（仅支付通道费 0.6%） |
| Android 侧载 APK | 同上 | **100%** |
| 华为 AppGallery | 建议 **¥29 / ¥59 / ¥129 / ¥399** | 85%（教育类 90%） |
| Apple App Store | 建议 **¥33 / ¥68 / ¥148 / ¥448** | 85%（小型企业计划） |
| 微信小程序 | **不卖会员**（iOS 禁止） | — |

> 为什么 App 内要贵一点？因为平台要抽 15%，如果和网页同价，你到手只有 85%。
> 同价也可以，但要接受实际收入下降。

## B3. 网页版怎么收钱（7 种方案）

| 方案 | 费率 | 开通难度 | 适合 |
|---|---|---|---|
| **支付宝当面付/手机网站支付** | 0.6% | 需企业营业执照 | ⭐ 国内首选 |
| **微信支付 Native/H5** | 0.6% | 需企业 + 认证 | ⭐ 国内首选 |
| 爱发电 | 5–6% | 个人可用 | 先跑起来 |
| Buy Me a Coffee / Ko-fi | 5% | 个人可用，海外 | 海外用户 |
| Stripe | 2.9% + $0.30 | 海外公司主体 | 海外 |
| Lemon Squeezy（数字商品） | 5% + $0.5 | 个人可用 | 全球、自动税务 |
| 激活码线下卖 | 0% | 自己做 | 老师/班级 |

### 方案 1：支付宝（推荐）

1. 企业支付宝 → 开放平台 https://open.alipay.com/ → 创建「电脑网站支付」或「手机网站支付」
2. 拿到 AppID、应用私钥、支付宝公钥
3. 在 `server.js` 加两个路由：`/api/pay/create`（下单）、`/api/pay/notify`（回调验签）
4. 回调验签通过后调用 `applyPro('all_year', 到期时间, 'alipay:订单号', '', 'all')`
5. 费率 0.6%，T+1 结算

### 方案 2：微信支付

1. 企业微信 → 商户平台 https://pay.weixin.qq.com/ → 申请「Native 支付」或「H5 支付」
2. 拿商户号、API v3 密钥、证书
3. 同样在 `server.js` 加下单 + 回调验签
4. 费率 0.6%

### 方案 3：爱发电（个人也能用，最快）

1. 注册 https://afdian.com/
2. 创建「方案」：月付 ¥58 / 年付 ¥388
3. 把方案链接放到 App 的「会员」页
4. 用户付款后你手动或通过 API 发激活码

### 方案 4：激活码（0 成本，现在就能用）

App 已经内置激活码系统：

- 老师/你生成班级码：会员页 → 「我是在老师：生成班级码」
- 用户在「会员 → 激活码」输入即开通
- 可卖：¥388 年卡 = 一个激活码

> 好处：**完全没有手续费**，适合先在朋友圈/家长群卖。

## B4. 各渠道的钱怎么到手

| 渠道 | 结算方式 |
|---|---|
| 网页版支付宝/微信 | 直接进你的企业账户，T+1 |
| Android 侧载 | 你自己收（支付宝/微信/激活码），100% 到手 |
| 华为 | 次月结算到你留的银行账户，满 ¥1000 起结 |
| Apple | 每月结算，满 $10 起结，需填银行信息 + 税务表 |
| 微信小程序 | 微信支付 T+1 到商户号 |

## B5. 建议的上线顺序（赚钱角度）

```
1. 今天    网页版 + 激活码（0 抽成，先验证有没有人买）
2. 这周    Android 侧载 APK（0 抽成，转化最高的用户群）
3. 1 个月  接支付宝/微信支付（0.6%，正规化）
4. 1–3 月  华为上架（15%，覆盖华为手机用户）
5. 半年后  Apple（15%，但只覆盖愿意付溢价的用户）
6. 看情况  微信小程序（只拉新，不卖）
```
