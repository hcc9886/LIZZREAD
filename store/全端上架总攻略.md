# 第 1 章 所有端的前提：营业执照

**没有执照 → 支付宝/微信支付都申请不了 → 小程序也上不了。**

|---|---|

| 3 | 填：姓名、身份证号、手机号 |
| 4 | 经营范围填：**文化创意服务；图书零售；软件开发；信息技术服务** |
| 5 | 起名：如「杭州XX文化创意工作室」 |
| 6 | 提交 → 1–3 个工作日 |
| 7 | 下载电子营业执照（PDF/JPG） |

**各城市政务 App**：
| 城市 | App |
|---|---|
| 浙江 | 浙里办 |
| 广东 | 粤省事 |
| 上海 | 随申办 |
| 北京 | 北京通 |
| 江苏 | 江苏政务服务 |
| 其他 | 搜索「XX省 政务服务」 |

**费用**：执照 ¥0，刻章 ¥0–200（可选）

## 1.2 办完之后你有了

| 东西 | 用途 |
|---|---|
| 营业执照 | 申请支付宝/微信支付、小程序、华为 |

### 2.2.4 Nginx 配置

```nginx
server {
    listen 80;
    server_name lizzread.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name lizzread.com;

    ssl_certificate     /etc/letsencrypt/live/lizzread.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/lizzread.com/privkey.pem;

    root /var/www/lizzread;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8765;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /download/ {
        proxy_pass http://127.0.0.1:8765;
    }

    location = /sw.js         { add_header Cache-Control "no-cache"; }
    location = /manifest.json { add_header Cache-Control "no-cache"; }
    location ~* \.(jpg|png|webp|woff2|js)$ { expires 30d; }
}
```

# 第 6 章 兑换券怎么运转

## 6.1 一张券的生命周期

```
你生成 → 你收钱 → 你发券 → 用户激活 → 记录防重复
```

## 6.2 四种模式

| 模式 | 你怎么做 | 手续费 |
|---|---|---|
| **手动卖** | 加微信 → 转账 → 生成券 → 发券 | 0 |
| **官网自动** | 网页版付款 → 自动生成券 → 显示复制 | 0.6% |
| **批量分销** | 生成 100 张 → 卖给老师/群主 | 0 |
| **手机号自动** | 用户填手机号 → 短信发券 | 0.6% + ¥0.045/条 |

## 6.3 生成兑换码

**App 里**：会员页 → 「🔑 我是在老师：生成班级码」

**命令行批量**：
```bash
node -e '
const c = () => Array.from({length:4},()=>"ABCDEFGHJKLMNPQRSTUVWXYZ23456789"[Math.floor(Math.random()*32)]).join("");
for(let i=0;i<20;i++) console.log("LZ-YEAR-"+c()+"-"+c());
'
```

## 6.4 防重复使用

- 服务端查 `data/vouchers.json`
- 一码一台设备（`seats:1`）
- 班级码 30 台共用（`seats:30`）
