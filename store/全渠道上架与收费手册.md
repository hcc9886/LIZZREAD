### 1.2 用户安装步骤

**iPhone / iPad（必须 Safari）**
1. Safari 打开 `hcc9886.github.io/LIZZREAD`
2. 点底部中间 **分享 ⬆️**

**Android（Chrome / 华为浏览器）**
1. 打开链接
2. 底部自动弹「把 LIZZREAD 装成 App」→ **安装**
3. 没弹窗：右上角 ⋮ → **安装应用**

**电脑（Chrome / Edge）**
地址栏右侧 **⊕** → 点一下

### 1.3 换自己域名的 5 种方式

**方式 A：Vercel（免费，最快）**
```bash
cd ~/Desktop/LIZZREAD
bash scripts/build-web.sh        # 生成 dist-web/（约 730MB）
npm i -g vercel
vercel login
vercel deploy dist-web --prod
```
得到 `https://xxx.vercel.app`

**方式 B：Netlify 拖拽**
1. 打开 https://app.netlify.com/drop
2. 把 `dist-web` 文件夹整个拖进去
3. 等 5–15 分钟上传完成

**方式 C：Cloudflare Pages**
1. https://dash.cloudflare.com/ → Workers & Pages → Create
2. 选 **Upload assets** → 上传 `dist-web`

**方式 D：阿里云 OSS + CDN（国内最快）**
1. https://oss.console.aliyun.com/ 新建 Bucket（华东1/华北2，公共读）
2. 用 ossbrowser 上传 `dist-web` 全部内容
3. Bucket → 基础设置 → 静态页面 → 默认首页 `index.html`
4. 开 CDN → 绑域名 → 申请免费 SSL

**方式 E：自己的服务器**
```bash
scp -r dist-web/* user@服务器:/var/www/lizzread/
```
Nginx：
```nginx
server {
    listen 443 ssl http2;
    server_name read.你的域名.com;
    root /var/www/lizzread;
    index index.html;
    ssl_certificate     /etc/letsencrypt/live/read.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/read.你的域名.com/privkey.pem;
    location = /sw.js         { add_header Cache-Control "no-cache"; }
    location = /manifest.json { add_header Cache-Control "no-cache"; }
    location / { try_files $uri $uri/ /index.html; }
}
```
证书：`certbot --nginx -d read.你的域名.com`

⚠️ 必须保留目录：`covers/ data/ books/ sentences/ dicts/ shared/ reader/ vendor/`

### 1.4 发新版
```bash
cd ~/Desktop/LIZZREAD
sed -i '' 's/lizzread_v27/lizzread_v28/' sw.js   # 每次 +1，必须改
git add -A && git commit -m "feat: xxx" && git push
```
2–5 分钟后用户就能收到更新。
