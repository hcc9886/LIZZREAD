## 1. PWA 网页版（✅ 已完成，今天就能用）

### 1.1 现状

- 地址：`https://hcc9886.github.io/LIZZREAD/`
- 部署：GitHub Actions 自动部署（`.github/workflows/pages.yml`），push 到 main 即更新
- 用户更新：打开时自动检测，底部出现「🎉 有新版本可用 / 立即更新」

### 1.2 用户怎么装

**iPhone / iPad（必须 Safari）**

1. Safari 打开链接
2. 点底部中间 **分享 ⬆️**
3. 下滑找 **「添加到主屏幕」**
4. 右上角 **添加**

**Android**

1. Chrome / 华为浏览器打开链接
2. 底部自动弹「把 LIZZREAD 装成 App」→ 点 **安装**
3. 没弹窗就去右上角 ⋮ → 「安装应用」

**电脑**：地址栏右侧出现 ⊕ 图标，点一下即可

### 1.3 换成你自己的域名（可选）

```bash
cd ~/Desktop/LIZZREAD
bash scripts/build-web.sh          # 生成 dist-web/（约 730MB）
```

把 `dist-web/` 全部上传到：Vercel / Netlify / Cloudflare Pages / 阿里云 OSS + CDN / 腾讯云 COS

⚠️ 必须保留目录结构：`covers/ data/ books/ sentences/ dicts/ shared/ reader/ vendor/`

## 3. 华为 AppGallery（材料齐，等你的资质）

### 3.1 你需要先办的两件事（⏳ 只有你能办）

| 事项 | 网址 | 耗时 | 费用 |
|---|---|---|---|
| 企业实名认证 | https://developer.huawei.com/consumer/cn/ | 1–3 天 | ¥0 |
| **软件著作权** | https://www.ccopyright.com.cn/ | 30 工作日（可加急） | ¥300–1000 加急费 |

> 个人开发者**不能**发布含付费内容的应用；要卖会员必须企业号。

### 3.2 上传材料（✅ 已准备好）

| 项目 | 文件 |
|---|---|
| APK | `dist/LIZZREAD-2.0.0-release.apk`（**华为只收 APK，不收 AAB**） |
| 图标 216×216 | `store/huawei/assets/icon-216.png` |
| 截图 ×6（1080×1920） | `store/huawei/assets/01~06-1080x1920.png` |
| 应用介绍 / 更新说明 | `store/huawei/上架文案.md` |
| 后台填写顺序 | `store/huawei/提交清单.md` |

### 3.3 后台 7 步

1. AGC → **我的应用 → 新建应用**，包名 `com.lizzread.app`
2. 分类选 **教育 → 阅读**
3. 上传图标 + 截图 + 介绍
4. **版本信息 → 上传 APK**
5. 内容分级全选「否」→ 年龄 3+
6. 隐私与安全表单：不收集个人身份信息
7. 上传软著 → **提交审核**（1–3 个工作日）

### 3.4 华为内购（要卖会员才需要）

AGC → **API 管理 → 开通「应用内支付服务」** → 商品管理建 4 个自动续期订阅：

| 商品 ID | 价格 |
|---|---|
| `com.lizzread.one.month` | ¥22/月 |
| `com.lizzread.all.month` | ¥48/月 |
| `com.lizzread.all.quarter` | ¥108/季 |
| `com.lizzread.all.year` | ¥328/年 |

然后下载 `agconnect-services.json` 放到 `android/app/`，服务端设 `HUAWEI_APP_ID/SECRET`。

## 4. 微信小程序（工程已生成 ✅）

### 4.1 三道硬门槛

| 门槛 | 说明 |
|---|---|
| 主体 | 必须**企业/个体工商户**，个人号不能选「教育-在线阅读」 |
| ICP 备案 | 2024-09 起强制，需已备案域名（7–20 天） |
| 内容合规 | 书籍必须公版，需能举证（我们的书全部来自 Project Gutenberg / 青空文库） |

### 4.2 工程在哪

`weapp/` 目录，已经可以直接导入微信开发者工具。

**你只需要改两处**：

- `weapp/app.js` → `SITE` 改成你已备案的 HTTPS 域名
- `weapp/project.config.json` → `appid` 改成你的小程序 AppID

### 4.3 九步上线

1. 注册小程序：https://mp.weixin.qq.com/ （邮箱不能注册过公众号）
2. 主体选**企业** → 对公打款验证 → 付 ¥300/年认证费 → 等 1–3 天拿 AppID
3. 域名 ICP 备案（7–20 天）
4. 小程序备案（后台 → 设置 → 基本设置 → 备案信息）
5. 部署 `dist-web/` 到已备案域名（必须 HTTPS）
6. 后台 → 开发 → 开发设置 → **业务域名** 添加你的域名，上传校验文件到网站根目录
7. 服务类目：教育 → 在线阅读（附《公版作品说明》）
8. 微信开发者工具 → 导入 `weapp/` → 填 AppID → 上传
9. 后台 → 版本管理 → 提交审核（1–7 天）→ 发布

### 4.4 关键限制

**iOS 端小程序禁止虚拟支付**（微信 + Apple 双限制），所以小程序适合「免费读 + 拉新」，不能卖会员。

### 4.5 被拒对策

| 被拒理由 | 对策 |
|---|---|
| 类目不符 | 改「教育-在线阅读」+ 公版作品说明 |
| 业务域名未配置 | 第 6 步 |
| 涉嫌版权 | 提交公版作品清单与来源链接 |
| 诱导分享 | 分享文案改中性 |
| 虚拟支付 | 移除会员入口（iOS 端） |

> 详细版见 `store/微信小程序-详细教程.md`
