# ① PWA 网页版（今天就能用，0 元）

## 1.1 部署（二选一）

### 方式 A：GitHub Pages（免费，已在 CI 里配好）

1. 打开仓库 https://github.com/hcc9886/LIZZREAD
2. **Settings → Pages**
3. **Source** 选 **GitHub Actions**（不要选 Deploy from a branch）
4. 回到 **Actions** 标签，找到 **Deploy web app to GitHub Pages**，点 **Run workflow**
5. 等 2–5 分钟变绿，访问：`https://hcc9886.github.io/LIZZREAD/`

> 仓库里已配好 `.github/workflows/pages.yml`，以后每次 push 到 main 会自动重新部署。

### 方式 B：自己的域名 / 其他托管

```bash
cd /Users/hcc/Desktop/LIZZREAD
bash scripts/build-web.sh        # 生成 dist-web/（约 730MB）
```

把 `dist-web/` 里**全部内容**上传到：

| 平台 | 命令 / 方式 | 备注 |
|---|---|---|
| Vercel | `npx vercel deploy dist-web --prod` | 免费，自动 HTTPS |
| Netlify | 网页拖拽 `dist-web` 文件夹 | 免费 |
| Cloudflare Pages | 连接 Git 仓库，构建目录填 `dist-web` | 免费，国内较快 |
| 阿里云 OSS | 控制台上传 → 开静态托管 → 绑 CDN | 国内最快 |
| 腾讯云 COS | 同上 | |
| Gitee Pages | 推到 Gitee → 服务 → Gitee Pages | 免费但要实名 |

⚠️ **必须保留目录结构**（`covers/ data/ books/ sentences/ dicts/ shared/ reader/ vendor/`），少一个就会 404。

## 1.2 给用户：装到桌面

### iPhone（必须 Safari）
1. Safari 打开链接
2. 底部 **分享 ⬆️** → 下滑找 **「添加到主屏幕」**
3. 右上角 **添加**

### Android
1. Chrome / 华为浏览器打开
2. 底部自动弹「把 LIZZREAD 装成 App」→ **安装**
   （没弹就去 ⋮ 菜单 → 安装应用）

### 电脑
地址栏右侧 **安装图标 ⊕** → 点一下

## 1.3 更新

用户下次打开会自动提示「🎉 有新版本可用 / 立即更新」。
你这边只需：

```bash
sed -i '' 's/lizzread_v27/lizzread_v28/' sw.js    # 每次 +1
git add -A && git commit -m "feat: xxx" && git push
```

# ② Android APK 侧载（0 元，立即分发）

## 2.1 产物

| 文件 | 用途 |
|---|---|
| `dist/LIZZREAD-2.0.0-release.apk` | 发给用户安装（131MB，正式签名） |

## 2.2 发给用户

- 微信「文件传输助手」发给对方 → 对方点开 → 允许「未知来源」
- 或放网盘贴链接
- 或用你的后端：`https://你的域名/download/LIZZREAD.apk`（已内置该路由）

## 2.3 发新版

```bash
APPVER=2.0.1 ./build-app.sh
# 产物自动进 dist/，同时更新 download/LIZZREAD.apk（供应用内更新）
```

用户端：**设置 → 关于 → 🔄 检查更新** → 有新版本点「下载安装包」→ 覆盖安装，数据全保留。

## 2.4 记住这件事

**`android/app/lizzread.keystore`（密码 `lizzread2026`）必须长期备份**。
丢了就无法覆盖升级，老用户只能卸载重装。

# ③ 华为 AppGallery（0 元，1–3 天审核）

## 3.1 前置（只有你能做）

| 事项 | 链接 | 耗时 |
|---|---|---|
| 企业实名认证 | https://developer.huawei.com/consumer/cn/ | 1–3 天 |
| 软件著作权（**必须**） | https://www.ccopyright.com.cn/ | 30 工作日（可加急） |

> 个人开发者**不能**发布含付费内容的应用；要卖会员必须企业号。

## 3.2 后台创建

1. https://developer.huawei.com/consumer/cn/service/josp/agc/index.html → **我的应用 → 新建应用**
2. 包名：`com.lizzread.app`（必须一致）
3. 分类：教育 → 阅读
4. 默认语言：简体中文

## 3.3 上传材料

| 项目 | 文件 |
|---|---|
| APK | `dist/LIZZREAD-2.0.0-release.apk`（**华为只收 APK，不收 AAB**） |
| 图标 216×216 | `store/huawei/assets/icon-216.png` |
| 截图 6 张 | `store/huawei/assets/0*-1080x1920.png` |
| 应用介绍 | 复制 `store/huawei/上架文案.md` |
| 隐私政策 | 你的 Pages 上的 `privacy.html` 地址 |

详细后台字段填写顺序见 `store/huawei/提交清单.md`。

## 3.4 提交审核

1–3 个工作日。常见退回原因：
- 软著未提供 → 补交
- 文案里没有写明「公版」
- 截图与实机不符

## 3.5 华为内购（要卖会员才需要）

AGC → **API 管理 → 开通「应用内支付服务」** →
**产品运营 → 商品管理** → 建 4 个自动续期订阅（ID 与苹果一致）→
下载 `agconnect-services.json` 放到 `android/app/` → 服务端设 `HUAWEI_APP_ID/SECRET`。

# ④ 微信小程序（需企业主体 + 备案）

## 4.1 三条路线

| 路线 | 工作量 | 建议 |
|---|---|---|
| **web-view 套壳** | 0.5 天 | ⭐ 先做这个 |
| 原生重写 | 15–30 人日 | 有收入后 |
| uni-app 转译 | 8–15 人日 | 折中 |

## 4.2 硬门槛（先确认）

- **企业主体**（个人号不能选教育类目）
- **ICP 备案**（2024 起小程序强制，7–20 天）
- **业务域名**：web-view 只能加载已备案并在后台配置的域名
- **iOS 端禁止虚拟支付**（微信 & Apple 双限制）→ 小程序适合拉新，不适合卖会员

## 4.3 套壳工程（我可以直接生成）

```
weapp/
├── app.json
├── project.config.json
└── pages/web/{web.wxml, web.js, web.json}
```

`web.wxml`：
```xml
<web-view src="{{url}}" bindmessage="onMessage"></web-view>
```

`web.js`：
```js
Page({
  data:{ url:'' },
  onLoad(o){
    const base='https://你的备案域名/LIZZREAD/index.html';
    this.setData({ url: base + '?lang=' + (o.lang||'en') + '&wx=1' });
  }
});
```

## 4.4 需要做的适配

微信 web-view 里没有 Service Worker、文件选择受限，需要：
- 检测 UA 含 `miniProgram` → 跳过 SW 注册
- 禁用「导入书籍 / 网址导入」
- 翻译走后端（域名加进 request 白名单）

## 4.5 上线步骤

1. 注册企业小程序：https://mp.weixin.qq.com/ （认证费 ¥300/年）
2. 完成 ICP 备案
3. 后台 → 开发设置 → **业务域名** 添加你的域名（上传校验文件）
4. 下载微信开发者工具 → 导入 `weapp/` → 填 AppID → 上传
5. 后台 → 版本管理 → 提交审核（1–7 天）

> 详细见 `store/微信小程序方案.md`。**告诉我你有没有企业营业执照**，我就把 `weapp/` 工程和 `index.html` 的小程序适配直接生成好。
