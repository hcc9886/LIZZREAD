## 二、兑换券的完整运转流程

### 2.1 一张券的生命周期

```
① 生成（你）
      ↓
② 收钱（你）
      ↓
③ 发券（微信 / 邮箱 / 短信）
      ↓
④ 用户激活（粘贴 → 立即生效）
      ↓
⑤ 记录（防重复使用）
```

### 2.2 你现在有三种发券方式

| 方式 | 你怎么做 | 用户怎么收到 | 需要什么 |
|---|---|---|---|
| **A. 微信里发券** | 你生成券 → 微信聊天发给用户 | 微信消息 | 无 |
| **B. 邮箱发券** | 用户在 App 填邮箱 → 自动拉起邮件 | 邮箱 | 无（`mailto:`） |
| **C. 手机号发券** | 用户在 App 填手机号 → 后端生成 → 短信 | 短信 | 阿里云短信 |

## 三、四种具体的运转模式（你选一种或组合）

### 模式 1：你手动卖（最简单，0 手续费）

**流程**：
1. 用户想买 → 加你微信
2. 你发收款码（微信/支付宝）→ 用户转账 ¥299
3. 你在会员页生成一张年卡券（`LZ-YEAR-XXXX-XXXX`）
4. 微信里把券发给他
5. 他在 iOS 小程序粘贴 → 开通

**优点**：0 手续费，今天就能做
**缺点**：需要人工，一天最多几十单

**你每天要做的事**：
```
收钱 → 生成券 → 发券 → 结束（每单 30 秒）
```

### 模式 2：官网付款自动发券（推荐，可规模化）

**流程**：
1. 用户在**电脑或安卓手机**打开网页版
2. 支付宝/微信付 ¥299
3. **服务器自动生成兑换码**，页面显示「券号 + 复制」
4. 用户在 iOS 小程序粘贴激活

**要改什么**：网页版支付成功后，多显示一个弹窗

```javascript
// 支付成功后
const voucher = await fetch('/api/voucher/issue', {...});
el.innerHTML = `付款成功！兑换码：<b>${voucher}</b>，可复制到小程序使用`;
```

**我来实现**，你只需配好支付。

### 模式 3：批量生成 + 分销（最赚钱）

**流程**：
1. 你一次生成 100 张年卡券
2. 卖给老师/家长群/分销商（比如 ¥200/张）
3. 他们自己加价卖给学生

**要改什么**：加一个「批量生成」按钮（我可以加）

### 模式 4：手机号自动发券（全自动）

**流程**：
1. 用户在 App 填手机号
2. 后端生成券 → 调阿里云短信发送
3. 用户收到短信 → 粘贴激活

**要改什么**：
```javascript
const SMS = require('@alicloud/sms-sdk');
const sms = new SMS({ AccessKeyId, AccessKeySecret });
await sms.sendSMS({
  PhoneNumbers: phone,
  SignName: 'LIZZREAD',
  TemplateCode: 'SMS_xxx',
  TemplateParam: JSON.stringify({ code: voucher })
});
```

**注意**：短信要钱（¥0.045/条）+ 签名审核（1–3 天）

## 五、防重复使用（已实现）

### 5.1 服务端校验

```
用户粘贴券 → POST /api/redeem {code, device}
                ↓
       服务端查 data/vouchers.json
                ↓
    已用过？→ 返回 409「已在另一台设备使用」
                ↓
   没用过 → 登记 device → 返回 ok
```

### 5.2 本地兜底

如果服务端挂了（离线），本地也能激活：
```
localStorage.lz_local_vouchers 记录本地生成的券
activateCode() 同时查 REDEEM_CODES + 本地表
```

### 5.3 一码一台设备

- `seats: 1` 的券：一台设备只能用一次
- `seats: 30` 的班级券：30 台设备共用
