# 第 2 章 三个收款渠道的详细做法

## 2.1 支付宝

### 申请
1. 打开 https://open.alipay.com/
2. 用**企业支付宝**登录（个体户也行）
3. 「控制台」→「网页/移动应用」→「创建应用」
4. 应用类型选 **「手机网站支付」**（手机网页）和/或 **「电脑网站支付」**
5. 提交审核（需营业执照），1–3 个工作日
6. 审核通过后拿到：**AppID**、**应用私钥**、**支付宝公钥**

### 费率与到账
- 费率 **0.6%**（教育类可申请更低）
- T+1 结算到企业账户
- 单笔最低 0.01 元

### 接入代码结构（我来写）
```
用户点「开通 ¥328」
  → POST /api/pay/create { plan:"all_year" }
  → 服务端调支付宝 alipay.trade.wap.pay，返回跳转链接
  → 用户支付
  → 支付宝回调 POST /api/pay/notify（验签）
  → 写订单表，标记已支付
  → 前端轮询 /api/pay/status?order=xxx
  → 成功后 applyPro('all_year', 到期时间, 'alipay:订单号', '', 'all')
```

## 2.2 微信支付

### 申请
1. 打开 https://pay.weixin.qq.com/
2. 注册**商户号**（需企业营业执照）
3. 提交资料，1–5 个工作日审核
4. 审核通过后拿到：**商户号 mchid**、**API v3 密钥**、**证书**

### 三种支付接口

| 场景 | 接口 | 用户怎么付 |
|---|---|---|
| 电脑网页 | **Native 支付** | 显示二维码，微信扫码 |
| 手机浏览器 / iPhone Safari | **H5 支付** | 直接拉起微信 App |
| 安卓小程序 | **JSAPI 支付** | 小程序内 wx.requestPayment |

### 费率与到账
- 费率 **0.6%**
- T+1 到商户号

### 为什么 iPhone 能用微信支付

**iPhone 用 Safari 打开网页版** → 走 H5 支付 → 正常拉起微信付款。
这条路径**不受 Apple 限制**，因为它不是 App Store 的应用。

**iPhone 用微信小程序** → 微信自己禁止 iOS 端虚拟支付，所以不能。

# 第 3 章 微信小程序为什么不能选个人主体

## 3.1 官方规则

小程序主体类型：**个人 / 企业（含个体户）/ 政府 / 媒体 / 其他组织**

| 主体 | 可选类目 | 能不能做在线阅读 |
|---|---|---|
| 个人 | 工具、生活服务等极少类目 | ❌ **不能** |
| 个体工商户 | 全部类目（含教育） | ✅ 能 |
| 企业 | 全部类目 | ✅ 能 |

**关键**：「教育 → 在线阅读」属于**需要资质的类目**，只对企业/个体户开放。
个人主体选了会被拒，理由是「类目与主体资质不符」。

## 3.2 个人主体硬做会怎样

1. 类目只能选「工具-信息查询」
2. 功能页一旦出现「整本书阅读」「会员付费」→ 审核判「超出类目」
3. 即使过了，也会被举报下架

## 3.3 最快的解决办法：办个体工商户

| 步骤 | 说明 | 时间 |
|---|---|---|
| 1 | 支付宝搜「个体工商户注册」或当地政务 App | 线上 |
| 2 | 提交身份证 + 手机号 + 经营范围（写「文化创意服务」） | 10 分钟 |
| 3 | 起名（如「XX文化创意工作室」） | — |
| 4 | 审核 | 1–3 天 |
| 5 | 下载电子营业执照 | 即时 |

**费用**：执照 ¥0，刻章 ¥0–200

**办完就能**：选「教育 → 在线阅读」上架小程序 + 申请微信支付商户号。

## 3.4 不想办执照的几个替代

| 方案 | 可行性 | 说明 |
|---|---|---|
| 个人主体做「词典工具」 | ⚠️ 勉强 | 不能叫阅读器、不能给整本书，很容易被拒 |
| 挂靠朋友的公司 | ✅ | 用对方主体注册，分成 |
| 只做 PWA + APK | ✅ | iPhone 用 Safari 添加到主屏幕，安卓装 APK，**完全覆盖** |
| 先上华为 | ✅ | 华为可以用个人号上免费应用 |
