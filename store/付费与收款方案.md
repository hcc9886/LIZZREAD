# 二、站内收款：三种方式

## 2.1 支付宝（网页 + APK）

| 项 | 内容 |
|---|---|
| 费率 | **0.6%** |
| 到账 | T+1 到企业账户 |
| 申请 | https://open.alipay.com/ → 创建应用 → 开通「手机网站支付」 |
| 需要 | 企业营业执照（个体户也可以） |
| 我需要你给 | AppID、应用私钥、支付宝公钥 |

**接入步骤**（我来写代码）：
1. 用户在 App 点「开通」→ 请求 `/api/pay/create`（传 plan）
2. 服务端用支付宝 SDK 生成支付链接/二维码
3. 用户支付完成 → 支付宝回调 `/api/pay/notify`
4. 服务端验签通过 → 写订单 → 前端轮询 `/api/pay/status`
5. 前端调用 `applyPro(plan, 到期时间, 'alipay:订单号', '', scope)`

## 2.2 微信支付（网页 + APK + 安卓小程序）

| 项 | 内容 |
|---|---|
| 费率 | **0.6%** |
| 到账 | T+1 到商户号 |
| 申请 | https://pay.weixin.qq.com/ → 申请「Native 支付 / H5 支付 / JSAPI 支付」 |
| 需要 | 企业营业执照 + 微信认证（小程序的话用同主体最好） |

**三种场景用不同接口**：

| 场景 | 微信支付接口 | 说明 |
|---|---|---|
| 网页版（电脑） | **Native 支付** | 生成二维码，扫码付 |
| 网页版（手机浏览器） | **H5 支付** | 直接拉起微信 |
| 安卓小程序 | **JSAPI 支付** | 小程序内调用 `wx.requestPayment` |
| iOS | ❌ 不用微信支付 | 微信规则禁止，见 2.5 |

|---|---|---|---|---|
| 网页版（电脑） | ✅ Native 扫码 | ✅ | ✅ | 全部可用 |

| 安卓小程序 | ✅ JSAPI | ⚠️ 需微信支付商户资质 | ✅ | 微信支付最顺 |
| **iOS 小程序** | ❌ 微信禁止 | ❌ 微信禁止 | ✅ | 提示改用激活码/网页版 |
| Apple App Store | ❌ | ❌ | ❌ | 只能用 IAP（Apple 抽 15%） |

## 3.1 关于「收费必须支持 iOS 微信支付」

**可以，但只在网页版/添加到主屏幕场景**：

| 场景 | 能否用微信支付 | 原因 |
|---|---|---|
| iPhone 用 **Safari 打开网页版** | ✅ 可以 | 不在 App Store 体系内，Apple 不管 |
| iPhone **添加到主屏幕的 PWA** | ✅ 可以 | 同上，本质还是网页 |
| iPhone 的**微信小程序** | ❌ 不可以 | 微信自己禁止 iOS 端虚拟支付 |
| iPhone 的 **App Store App** | ❌ 不可以 | Apple 强制走 IAP |

**结论**：iPhone 用户**用 Safari 打开网页版或添加到主屏幕**就能微信支付。
这也正是我们推荐的 iPhone 方案。

# 四、小程序为什么不能选个人主体

## 4.1 官方规则

微信小程序注册时主体类型可选：个人、企业（含个体户）、政府、媒体、其他组织。

**个人主体被限制的类目**：不能做以下内容
- 电商平台、付费内容
- 医疗、金融、教育（部分）
- 直播、社交
- **在线阅读 / 数字内容售卖**

个人主体只能选「工具」「生活服务」等极少数类目，
而**「教育 → 在线阅读」只有企业/个体户才能选**。

## 4.2 没有企业资质怎么办

| 方案 | 说明 | 成本 |
|---|---|---|
| **办个体工商户** | 最快，很多地区 1–3 天线上办结 | ¥0–300 |
| 挂靠已有企业 | 找有执照的朋友/公司合作 | 分成 |
| 用个人主体做「工具」类 | 只能做"词典/翻译"，**不能叫阅读器、不能提供整本书阅读**，容易判违规 | ¥0 |
| 暂时不上小程序 | 用 PWA + APK 覆盖所有人 | ¥0 |

**推荐：办个体工商户**（如"XX文化工作室"），这是最省事的正规路径。

## 4.3 个体户能过审吗

能。个体户属于企业主体的一种，可以选「教育 → 在线阅读」，只需提供：
- 营业执照
- 《公版作品说明》（写明全部为 Gutenberg 公版）

# 五、办理个体工商户的步骤

1. **线上申请**：支付宝搜索「个体工商户注册」或当地政务 App（如"随申办""粤省事""浙里办"）
2. **提交材料**：身份证 + 手机号 + 经营范围（写「文化创意服务；图书零售」）
3. **名称**：如「XX文化创意工作室」
4. **审核**：1–3 个工作日
5. **拿执照**：电子营业执照直接下载
6. **对公账户**（可选）：个体户可用个人账户收款，但接支付宝/微信支付建议开对公户

**费用**：营业执照 ¥0；刻章 ¥0–200；对公账户 ¥0–500/年（部分银行免费）
