# iOS 小程序收费方案（改良版：兑换中心）

> 原方案：iOS 小程序直接跳转浏览器付费。
> **技术上能跳，但审核通不过**（微信明确禁止 iOS 小程序引导外部支付）。
> 所以改良为 **兑换中心**：合规、可落地、体验接近"付款即开通"。

---

## 一、为什么不能直接跳转浏览器付费

| 规则 | 内容 | 后果 |
|---|---|---|
| 微信《小程序运营规范》3.4 | 不得引导用户跳转外部进行虚拟支付 | 跳转即违规 |
| 微信 iOS 规则 | iOS 小程序不开放虚拟支付 | 支付按钮都调不起来 |
| Apple 3.1.1 | App 内不得引导外部购买 | 被举报即封 |

**结论**：把"去浏览器付款"做成按钮，一定被拒。要把**动作**藏起来，只留**结果**。

## 二、改良方案：兑换中心（Compliance-safe）

### 2.1 核心思路

```
用户想要会员
   ↓
点「开通」→ 打开「会员兑换中心」
   ├─ ① 有兑换券 → 粘贴 → 立即激活 ✅
   ├─ ② 没兑换券 → 选获取方式
   │     ├─ 联系客服（微信里发券）
   │     ├─ 电脑/安卓网页版订阅后自动发券
   │     └─ 同学转让（一码一用）
   └─ ③ 填邮箱/手机号 → 生成券 → 自动发送
```

**关键：界面上不出现「购买」「支付」「价格」「去某某网站付款」这些词。**

### 2.2 兑换券怎么发放到用户手里（你问的三种）

| 发放方式 | 实现 | 体验 |
|---|---|---|
| **① 直接兑换码** | 客服微信发券 → 用户粘贴 | 最简单，✅ 已实现 |
| **② 邮箱** | 填邮箱 → 生成券 → 自动拉起邮件 | ✅ 已实现 |
| **③ 手机号** | 填手机号 → 生成券 → 客服短信发 | ✅ 已实现（需短信通道） |
| ④ 微信服务通知 | 需后端 + 模板消息 | 需订阅消息授权 |

## 三、兑换券的三种来源（你实际怎么卖）

### 来源 1：客服发券（最快）

**流程**：
1. 用户在 iOS 小程序点「发送兑换券到我」→ 填手机号
2. 你收到申请 → 微信加用户 → 收款（微信/支付宝转账）
3. 你在「会员 → 生成班级码/兑换券」里生成券 → 微信里发给他
4. 用户粘贴激活

**优点**：100% 可控，0 手续费
**缺点**：需要人工，不能自动化

### 来源 2：网页版订阅后自动发券（推荐）

**流程**：
1. 用户在**电脑或安卓手机**打开网页版
2. 用支付宝/微信付 ¥328
3. 服务器收到回调 → 生成兑换券 → 显示「券号 + 复制按钮」
4. 用户在 iOS 小程序粘贴激活

**优点**：自动化，0 人工
**缺点**：用户需要换设备

### 来源 3：批量生成 + 分销（最赚钱）

**流程**：
1. 你在会员页批量生成 100 张年卡券
2. 卖给分销商/老师/家长群
3. 他们自己转手

**优点**：一次性卖完，0 手续费
**缺点**：需要渠道

## 四、合规红线（必须遵守）

| ✅ 可以 | ❌ 不可以 |
|---|---|
| 输入兑换券激活 | 出现「¥328」「立即购买」 |
| 「兑换券可从客服获取」 | 「去 www.xxx.com 付款」 |
| 「已有账号可在其他设备登录」 | 「跳转支付宝/微信支付」 |
| 「同学可以转让券」 | 「扫码付款享 8 折」 |
| 显示「iOS 版不提供在线购买」 | 显示价格和购买按钮 |

**核心原则**：只讲「怎么用券」，不讲「怎么买」。

## 五、三种发放方式的具体实现

### 5.1 直接兑换码（已实现）

```javascript
// 用户在兑换中心粘贴
const ok = await activateCode(code, true);
if(ok) localStorage.setItem("lz_voucher", code);
```

兑换码格式：`LZ-YEAR-A3F9-K2M8`

### 5.2 邮箱发放（已实现）

```javascript
// 用户填邮箱 → 生成券 → 拉起邮件
window.location.href = "mailto:" + email + "?subject=...&body=券号...";
```

**注意**：`mailto:` 只能拉起用户本地邮箱，无法真正"发送"。
要实现真正的邮件发送，需要后端接 SMTP（如 SendGrid 免费 100 封/天）。

### 5.3 手机号发放（需短信通道）

```javascript
// 用户填手机号 → 后端调短信 API
await fetch("/api/voucher/issue", { body: JSON.stringify({ phone }) });
```

**短信通道**：
| 平台 | 价格 | 备注 |
|---|---|---|
| 阿里云短信 | ¥0.045/条 | 需签名审核 |
| 腾讯云短信 | ¥0.04/条 | |
| 榛子短信 | ¥0.035/条 | 便宜 |

**接入代码（阿里云示例）**：
```javascript
const SMS = require('@alicloud/sms-sdk');
const sms = new SMS({ AccessKeyId, AccessKeySecret });
await sms.sendSMS({
  PhoneNumbers: phone,
  SignName: 'LIZZREAD',
  TemplateCode: 'SMS_123456789',
  TemplateParam: JSON.stringify({ code: voucher })
});
```

### 5.4 微信服务通知（最顺滑，需订阅消息）

**流程**：
1. 小程序里让用户点「订阅消息」（一次授权一次推送）
2. 付款后后端调微信接口发模板消息
3. 用户在微信服务通知里看到券号

**限制**：一次授权只能发一次，需用户主动点。

## 九、一句话总结

> **iOS 小程序不卖会员，只"兑换"会员。**
> 券在你手里、在你微信里、在网页版付款后，用户只需粘贴一次。
> 这样既符合微信规则，又不会让 iPhone 用户流失。
