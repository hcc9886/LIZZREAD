# 第 1 章 iOS 小程序怎么收费

## 1.1 先说结论：**iOS 小程序不能直接收钱**

| 规则来源 | 内容 |
|---|---|
| 微信《小程序平台运营规范》 | 小程序内虚拟支付必须用微信支付 |
| 微信 iOS 端政策 | **iOS 小程序不开放虚拟支付能力** |
| Apple App Store 3.1.1 | App 内数字内容必须用 IAP，且不能引导外部支付 |

三层叠加的结果：**iOS 小程序里，任何"买会员"的按钮都不能真的发起支付。**

## 1.2 那 iOS 用户怎么付钱？4 条路

### 路 1：激活码（✅ 已实现，100% 可用）

用户在 iOS 小程序里输入激活码 → 立即开通。
这是**唯一完全合规且体验可接受**的方式。

**流程**：
```
你在网页版/微信/闲鱼卖激活码（¥328 年卡）
   ↓
用户拿到 20 位激活码
   ↓
在 iOS 小程序 → 会员 → 输入激活码 → 开通
```

**费率**：0%（你收钱时用的渠道决定，见 1.3）

**代码位置**：会员页「激活码」输入框（已上线）
**已验证激活码**：
- `wansuiwansuiwanwansui1313113` — 永久
- `nulixuexiya2027` — 一年
- `lizzzhaohaoyon!!!` — 单语言月卡

### 路 2：引导到网页版付款（✅ 已实现）

iOS 小程序点「开通」时，弹窗给出**复制网页版链接**按钮：

```
受微信规则限制，iOS 端小程序内不能直接购买虚拟内容。
三种开通方式：
① 用激活码在此直接开通
② 复制链接到 Safari 打开网页版，用微信/支付宝支付
③ 换安卓手机打开小程序，可用微信支付
```

⚠️ 注意：微信审核员会看「有没有引导外部支付」。
**合规做法**：只提供"复制网页版链接"，不直接放支付宝/微信支付按钮，也不写"去某某网站付款享折扣"这类诱导语。

### 路 3：换安卓手机（✅ 安卓小程序支持微信支付）

同一小程序，安卓机上显示「微信支付」按钮，iOS 上显示激活码引导。

**代码已实现**：`payChannelState()` 自动判断
```js
if(mini && ios) return { mode:"mini_ios", pay:false, code:true };  // iOS
if(mini)        return { mode:"mini_android", pay:true, code:true }; // 安卓
```

### 路 4：iOS App Store 版（暂不做）

需要 $99/年 + 15% 抽成。你说「Apple 暂时不动」，所以跳过。

## 2.2 支付宝接入详细步骤

### 2.2.1 申请
1. 打开 https://open.alipay.com/
2. 用**企业支付宝**登录（个体户也可以，需先有营业执照）
3. 控制台 → **网页/移动应用** → **创建应用**
4. 应用信息：
   - 应用名称：LIZZREAD
   - 应用类型：**手机网站支付**（必选）+ 电脑网站支付（可选）
   - 网址：你的域名
5. 上传营业执照 → 提交审核（1–3 个工作日）

### 2.2.2 生成密钥（关键）
1. 应用审核通过后 → 应用详情 → **开发设置** → **接口加签方式**
2. 选 **公钥模式** → 下载**支付宝密钥生成工具**
3. 工具里点「生成密钥」→ 得到：
   - **应用私钥**（自己保存，绝不外泄）
   - **应用公钥**（填到支付宝后台）
4. 填完应用公钥 → 支付宝会给你 **支付宝公钥**

### 2.2.3 拿到三样东西

| 名称 | 样子 | 用在哪 |
|---|---|---|
| AppID | `2021000000000000` | `ALIPAY_APP_ID` |
| 应用私钥 | `-----BEGIN RSA PRIVATE KEY-----...` | `ALIPAY_PRIVATE_KEY` |
| 支付宝公钥 | `-----BEGIN PUBLIC KEY-----...` | `ALIPAY_PUBLIC_KEY` |

### 2.2.4 填到服务器
```bash
export ALIPAY_APP_ID=2021000000000000
export ALIPAY_PRIVATE_KEY="$(cat 应用私钥.txt)"
export ALIPAY_PUBLIC_KEY="$(cat 支付宝公钥.txt)"
export PAY_BASE_URL=https://你的域名.com
```

    # 后端接口代理

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;

    location /download/ {

## 4.2 APK 怎么接支付

APK 是网页套壳（Capacitor），里面的页面和后端通信：
```
APK 里的 index.html → fetch(https://你的域名/api/pay/create) → 后端下单
                   → 跳转支付宝/微信
                   → 回调后端 → 前端轮询 → 开通
```

**需要在 `build-app.sh` 里设置后端地址**：
```bash
export LZ_API=https://你的域名
./build-app.sh
```

这样 APK 打开时会连接你的后端，支付、翻译、词典都能用。

## 4.3 APK 怎么分发

| 方式 | 说明 |
|---|---|
| 微信文件传输助手 | 发给朋友最简单 |
| 网盘 | 百度/阿里云盘分享链接 |
| 官网下载 | `https://你的域名/download/LIZZREAD.apk`（路由已内置） |
| 应用商店 | 见第 5 章华为 |
