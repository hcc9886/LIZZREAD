# 两套收费方式（最终版）

> 改版说明：**兑换码/兑换券/邮箱发券/手机号发券，全部只保留在 iOS 小程序里**。
> 其他端（网页版 / 安卓 APK / 华为）**全部走直接支付**，不再出现任何兑换券概念。

| 端 | 收费方式 | 用户看到什么 |
|---|---|---|
| **网页版（电脑/手机 Safari）** | 支付宝 / 微信支付 | 点「开通」→ 选支付方式 → 付款 → 自动开通 |

## 二、iOS 小程序怎么付款（核心问题）

### 2.1 关键事实：**web-view 里可以付款**

| 位置 | 能否付款 | 原因 |
|---|---|---|
| 小程序**原生页面** | ❌ 不能 | 微信 iOS 不开放虚拟支付 |
| 小程序里的 **web-view 页面** | ✅ **能** | 本质是网页，走浏览器支付通道 |

这条是微信规则里的空隙：**原生页面不行，web-view 里的网页可以**。

### 2.2 具体流程

```
用户在 iOS 小程序点「开通」
        ↓
弹出「打开官方订阅页」按钮
        ↓
小程序跳转到 web-view 页面（你自己的域名）
        ↓
页面里显示：支付宝支付 / 微信支付
        ↓
用户用微信支付（H5 拉起微信）或支付宝付款
        ↓
支付回调 → 服务器标记订单已支付
        ↓
web-view 页面轮询查到 paid → 自动开通会员
        ↓
用户回到小程序，会员已生效
```

### 2.3 代码实现（已完成）

**小程序端** `index.html`：
```javascript
function openMiniIosPayPage(){
  const url = "https://你的域名/index.html?iosmini=1&pay=1&plan=all_year";
  // 小程序内跳到 web-view 页面
  wx.miniProgram.navigateTo({ url: "/pages/web/web?url=" + encodeURIComponent(url) });
}
```

**web-view 页面加载时自动弹支付**：
```javascript
async function autoOpenPayFromMini(){
  const q = new URLSearchParams(location.search);
  if(q.get("pay") !== "1") return;
  selectPayMethod(q.get("plan") || "all_year");
}
```

**支付方式判断**（web-view 里允许支付）：
```javascript
function payChannelState(){
  const inWebviewPage = /[?&]pay=1/.test(location.search);
  if(mini && ios && !inWebviewPage) return { mode:"mini_ios", pay:false };  // 原生页
  if(inWebviewPage) return { mode:"web", pay:true };                        // web-view 页
  ...
}
```

### 2.4 小程序需要配的东西

1. **业务域名**：你的域名加到小程序后台（web-view 白名单）
2. **web-view 页面**：`weapp/pages/web/web.js` 已支持 `?url=` 参数
3. **支付商户**：支付宝/微信商户号（网页版同款）
4. **服务器**：能收支付回调（HTTPS）

### 2.5 实测

| 场景 | 结果 |
|---|---|
| 小程序原生页点「开通」 | ✅ 弹「打开官方订阅页」 |
| web-view 订阅页 | ✅ `{"mode":"web","pay":true}`，显示支付宝/微信 |

## 三、网页版怎么收费（接入什么）

### 3.1 接入支付宝

| 步骤 | 操作 | 链接 |
|---|---|---|
| 1 | 企业支付宝登录开放平台 | https://open.alipay.com/ |
| 2 | 创建应用 → 选「手机网站支付」 | |
| 3 | 上传营业执照 | |
| 4 | 审核 1–3 天 | |
| 5 | 开发设置 → 公钥模式 → 生成密钥 | |

**拿到 3 样**：AppID、应用私钥、支付宝公钥
**费率**：0.6%

### 3.2 接入微信支付

| 步骤 | 操作 | 链接 |
|---|---|---|
| 1 | 注册商户号 | https://pay.weixin.qq.com/ |
| 2 | 提交营业执照等 | |
| 3 | 审核 1–5 天 | |
| 4 | 账户中心 → API 安全 → 设 APIv3 密钥 | |
| 5 | 申请 API 证书 → 下载 apiclient_key.pem | |
| 6 | 产品中心 → AppID 授权 | |

**拿到 5 样**：mchid、AppID、APIv3 密钥、证书序列号、私钥
**费率**：0.6%

### 3.3 填到服务器

```bash
export ALIPAY_APP_ID=2021...
export ALIPAY_PRIVATE_KEY="$(cat 应用私钥.pem)"
export ALIPAY_PUBLIC_KEY="$(cat 支付宝公钥.pem)"

export WXPAY_MCHID=1600...
export WXPAY_APPID=wx...
export WXPAY_API_V3_KEY=32位密钥
export WXPAY_SERIAL=证书序列号
export WXPAY_PRIVATE_KEY="$(cat apiclient_key.pem)"

export PAY_BASE_URL=https://你的域名.com
node server.js 8765
```

### 3.4 已写好的代码

| 层 | 文件 | 内容 |
|---|---|---|
| 后端 | `server/pay.js` | RSA2 签名验签、微信 v3 签名、AES 解密、订单存储 |
| 后端 | `server.js` | 5 个支付接口 |
| 前端 | `index.html` | 下单、跳转/二维码、轮询、自动开通 |

**实测**：
```
下单 → LZ20261124B69E54FA
验签回调 → success
状态 → {"status":"paid","plan":"all_year","days":366}
```

## 八、给用户看到的差异

| 端 | 点「开通」后看到 |
|---|---|
